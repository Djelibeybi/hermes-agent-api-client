## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller-owned `httpx.AsyncClient` to library stream | The library may own the response only; the injected client and its pool belong to the caller (Home Assistant). |
| Library exception and frame state to consumer | Exceptions, tracebacks and retained generator frames cross back to the consumer and may be logged. |
